# 注音趣 — 檔案功能說明

v1 範圍：注音符號單音點選學習。37 個注音符號（聲符 21 + 韻符 16）以固定清單顯示，
每個符號可搭配一張老師建立的意象圖片與口訣（後台 `admin/zhuyin.js` 管理，
存在全校共用的 `zhuyinSounds` collection，文件 ID = 符號本身）。

v2 新增：仿認字趣的練習／測驗模式（辨識式選擇題，非手寫——HanziWriter 公開筆順資料
沒有涵蓋注音符號，無法比照識字趣的描摹/默寫）。「聽音選字」「看字選音」為兩個獨立方向，
精熟度／進度各自累計，互不影響。

v3 新增：頂層再分「單音」（37 符號）／「結合韻」（教育部標準 22 個結合韻，`zhuyinCombinedSounds`
collection，文件 ID = 結合韻本身，如「ㄧㄚ」）兩大區，各自擁有完整一套符號瀏覽／聽音選字／
看字選音／練習／測驗功能，資料與精熟度完全獨立。後台編輯介面（`admin/zhuyin.js`）用分頁切換
兩區，UI 與操作邏輯共用同一套。

- `index.html` — App 入口，固定 Topbar + 頁面容器
- `zhuyin.css` — App 專屬樣式
- `js/nav.js` — 頁面切換（`page-zy-section-select`〔最頂層：單音／結合韻〕／`page-mode-select`／
  `page-grid`／`page-zy-menu`／`page-zy-practice`／`page-zy-exam`／`page-zy-exam-round-result`／
  `page-zy-exam-result`／`page-settings`）、PAGE_STACK、Hub 通訊（`zhuyin-back-to-hub`／`zhuyin-logout`）
- `js/state.js` — 單音固定清單（`ZHUYIN_INITIALS`／`ZHUYIN_FINALS`）＋結合韻固定清單
  （`ZY_COMBINED_YI`／`ZY_COMBINED_WU`／`ZY_COMBINED_YU`／`ZY_COMBINED`）；`zySection`（'single'|'combined'）
  控制目前是哪一區，`zyActiveSymbols()`／`zyActiveData()`／`zyActiveStatusMap()` 是各處讀取「目前這區」
  資料的統一入口；`loadZhuyinData()`／`loadZhuyinCombinedData()` 分別載入 `zhuyinSounds`／
  `zhuyinCombinedSounds`（App 啟動時兩份都會先載好）；`zyDirection`／`zySymbolStatus`
  （`{single:{listenStatus,readStatus}, combined:{listenStatus,readStatus}}`，存在
  `students/{id}/progress/zhuyin` 的 `listenStatus`／`readStatus`／`combinedListenStatus`／
  `combinedReadStatus` 四個欄位）、`shuffle()`／`buildZyOptions()` 出題共用工具
- `js/voice.js` — TTS 朗讀，一律用 `pickBestZhVoice()`；`zySpeakSymbol()` 只唸符號本身（查
  `zyActiveData()`，有教師錄音優先播錄音），`zySpeakPhrase()` 唸完整口訣（沒有口訣時退回唸符號）
- `js/menu.js` — 區域選擇（`enterZySection()`）；符號瀏覽網格（`renderZhuyinGrid()`／`enterZyGrid()`，
  分組依 `_zyGroupsForSection()`：單音是聲符／韻符，結合韻是ㄧ系／ㄨ系／ㄩ系）；練習／測驗方向選單
  （`enterZyDirection()`／`renderZyMenu()`／`renderZyMenuProgress()`）、自選範圍勾選
  （`zyEnterSelectMode()` 等，比照認字趣「全部練習／自選練習」）
- `js/practice.js` — 練習模式：第一輪固定順序、之後隨機出題（範圍依 `zyActiveSymbols()`），
  答錯可重選，精熟度星數即時計算，不寫入 Firestore
- `js/exam.js` — 測驗模式：一律涵蓋目前這區的全部符號，每題只能答一次、答錯公佈正解，
  未過關的題目下一輪重考，直到整輪全對；完成後把每個符號的精熟狀態存回 `zySymbolStatus`
- `js/init.js` — 啟動、自動登入（含 `zySymbolStatus` 兩區四個狀態一併載入）、設定頁（頭像／主題）

後台管理（`admin/zhuyin.js`）：`_zyAdminSection` 控制目前編輯哪一區，`_zySwitchAdminSection()`
切換分頁（Firestore collection 跟著換），編輯 Modal／圖片上傳／錄音功能兩區完全共用同一套程式碼。

# 注音趣 — 檔案功能說明

v1 範圍：注音符號單音點選學習。37 個注音符號（聲符 21 + 韻符 16）以固定清單顯示，
每個符號可搭配一張老師建立的意象圖片與口訣（後台 `admin/zhuyin.js` 管理，
存在全校共用的 `zhuyinSounds` collection，文件 ID = 符號本身）。

- `index.html` — App 入口，固定 Topbar + 頁面容器
- `zhuyin.css` — App 專屬樣式
- `js/nav.js` — 頁面切換（`page-grid`／`page-settings`）、PAGE_STACK、Hub 通訊（`zhuyin-back-to-hub`／`zhuyin-logout`）
- `js/state.js` — 37 個符號的固定清單（`ZHUYIN_INITIALS`／`ZHUYIN_FINALS`）、`loadZhuyinData()` 載入 `zhuyinSounds`
- `js/voice.js` — TTS 朗讀，一律用 `pickBestZhVoice()`；`zySpeakSymbol()` 只唸符號本身，`zySpeakPhrase()` 唸完整口訣（沒有口訣時退回唸符號）
- `js/menu.js` — 渲染符號表格（`renderZhuyinGrid()`），每張卡片上半是符號按鈕、下半是圖片按鈕，各自獨立可點
- `js/init.js` — 啟動、自動登入、設定頁（頭像／主題）

# 注音趣 — 檔案功能說明

v1 範圍：注音符號單音點選學習。37 個注音符號（聲符 21 + 韻符 16）以固定清單顯示，
每個符號可搭配一張老師建立的意象圖片與口訣（後台 `admin/zhuyin.js` 管理，
存在全校共用的 `zhuyinSounds` collection，文件 ID = 符號本身）。

v2 新增：仿認字趣的練習／測驗模式（辨識式選擇題，非手寫——HanziWriter 公開筆順資料
沒有涵蓋注音符號，無法比照識字趣的描摹/默寫）。「聽音選字」「看字選音」為兩個獨立方向，
精熟度／進度各自累計，互不影響。

- `index.html` — App 入口，固定 Topbar + 頁面容器
- `zhuyin.css` — App 專屬樣式
- `js/nav.js` — 頁面切換（`page-mode-select`／`page-grid`／`page-zy-menu`／`page-zy-practice`／
  `page-zy-exam`／`page-zy-exam-round-result`／`page-zy-exam-result`／`page-settings`）、
  PAGE_STACK、Hub 通訊（`zhuyin-back-to-hub`／`zhuyin-logout`）
- `js/state.js` — 37 個符號的固定清單（`ZHUYIN_INITIALS`／`ZHUYIN_FINALS`／`zyAllSymbols`）、
  `loadZhuyinData()` 載入 `zhuyinSounds`；`zyDirection`／`zySymbolStatus`（`listenStatus`／`readStatus`，
  存在 `students/{id}/progress/zhuyin`）、`shuffle()`／`buildZyOptions()` 出題共用工具
- `js/voice.js` — TTS 朗讀，一律用 `pickBestZhVoice()`；`zySpeakSymbol()` 只唸符號本身（有教師錄音優先播錄音），
  `zySpeakPhrase()` 唸完整口訣（沒有口訣時退回唸符號）
- `js/menu.js` — 符號瀏覽網格（`renderZhuyinGrid()`）；練習／測驗方向選單（`enterZyDirection()`／
  `renderZyMenu()`／`renderZyMenuProgress()`）、自選範圍勾選（`zyEnterSelectMode()` 等，比照認字趣「全部練習／自選練習」）
- `js/practice.js` — 練習模式：第一輪固定順序、之後隨機出題，答錯可重選，精熟度星數即時計算，不寫入 Firestore
- `js/exam.js` — 測驗模式：一律涵蓋全部 37 符號，每題只能答一次、答錯公佈正解，
  未過關的題目下一輪重考，直到整輪全對；完成後把每個符號的精熟狀態存回 `zySymbolStatus`
- `js/init.js` — 啟動、自動登入（含 `zySymbolStatus` 一併載入）、設定頁（頭像／主題）

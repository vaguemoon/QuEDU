# 課文趣 — 檔案功能說明

給特教（輕度智能障礙）學生上課用的電子課本。跟「考卷報讀」（`apps/quiz/word-to-reader/`，
定位為段考時的測驗工具）分開，也不綁共用課程資料（`curriculum` collection，全校共用的官方
課本生字詞清單，只有超級管理者能編輯）——因為特教老師的課文是自己改寫、簡化過的，本來就沒有
對應的官方課次可以掛。

**課文身分＝`teacherUid` + `grade`（年級冊次，如「一上」）+ `lesson`（課次，如「1」）**，
跟教師題庫（`questions` collection，`admin/quiz-bank.js` 管理）的課次概念完全共用。
**配套生字詞不用老師另外輸入**：課文趣會自動抓該課「詞語解釋」「詞語填空」兩種題型的
**答案欄**當生字詞、**題幹欄**當老師自己的解釋——老師本來就會用 Excel 把題目和答案（生字詞）
一起上傳，這裡直接重用那份資料，不用重複輸入。

## 資料流

1. 老師在 `admin/quiz-bank.js`（一般教師後台，不需要超級管理者權限）原本的題庫課次列表，
   每一課旁邊多一個「📖 課文」按鈕，展開後可以：
   - 上傳全文（可用 .docx/.txt/.odt/.pdf 自動轉檔，也能手打/貼上；空行會保留成段落留白），
     存進新的 `lessonTexts/{docId}` collection
     （`docId = 't_' + encodeURIComponent(teacherUid|grade|lesson)`）
   - 設定「破音字讀音調整」（`pronFixes: {原字: 同音替代字}`），整課同一字元都套用——
     發音與查詢彈窗注音都改用替代字的讀音，解釋仍查原字，避免誤用替代字字義
   - 勾選要分享的班級，存進 `classes/{classId}/sharedLessonTexts/{docId}`（學生實際讀取的來源，
     `pronFixes` 也會一併存一份快照）
2. 學生打開課文趣，`js/state.js` 的 `loadEtLessonList()` 查詢自己所有班級的
   `sharedLessonTexts`，列成一張清單
3. 點開一篇課文後，`_etLoadVocab()` 用 `teacherUid + grade`（2 欄位查詢，避免額外複合索引）
   撈該老師自己的題目，前端再過濾
   `lesson` + `type in ['詞語解釋','詞語填空']`，答案欄組成本課生字詞清單

## 閱讀畫面機制

- 課文全文逐字渲染成 `<span>`，中文字可點擊發音／可用 Pointer Events 拖曳連續選取圈成一個詞
  （限同一行內，觸控/滑鼠通用）；課文裡的空行會保留成一段留白（`etLines` 裡的 `blank:true`
  標記），不再被整個吃掉
- 破音字讀音調整（`etPronFixes`）：發音（`etSpeak`／`etSpeakWithCallback`）跟查詢彈窗的注音
  顯示都會先把設定過的原字換成老師指定的同音字再處理，畫面上顯示的原文完全不受影響
- 圈到（或點到）文字：**一律先發音＋查詢**——符合本課生字詞的話優先顯示老師自己寫的解釋
  （比萌典的通用解釋更貼近學生程度），否則退回查萌典 API；查到的詞若剛好在詞語圖庫
  （`wordImages`）裡有教學圖片，一併顯示。全程沒有「圈錯」的失敗狀態，查詢一定有結果，
  只有「符合本課生字詞」才會額外標色、算進度、存進度
- 每句前面有喇叭鍵（`etSpeakLine()`），點了只唸那一句，唸的時候反白那一行；沒有整課自動
  連續朗讀模式
- 語速可調 0.5～1.2（－／＋按鍵，這個服務對象常需要比一般更慢的語速），字體大小可調
  （Ａ－／Ａ＋按鍵），兩者都會記住這台裝置上次的設定（`localStorage`）
- 進度列＋工具列用 `position: sticky` 釘在閱讀頁頂端，捲動課文時不會跟著移動
- 「本課已找到的生字詞」清單裡的 chip 可以點，一樣發音＋彈出查詢視窗（圖片＋老師解釋），
  複習時不用回課文裡重新圈字
- 注音字型（`et-font.css` 的 `@font-face`）不是一進 App 就載入，是 `enterEtLesson()` 進閱讀
  畫面那一刻才動態插入 `<link>`（`_etLoadFontFace()`）。課文清單頁完全不碰這顆 7MB 的字型檔，
  不會跟載入課文清單用的 Firestore 查詢搶頻寬；字型本身字形已內含注音，裁字沒辦法有效縮小
  （實測過，省不到 5%），所以用「延後到真正需要時才載入」取代「縮小檔案」

## 檔案清單

- `index.html` — App 入口，`page-list`（課文清單）→ `page-reader`（閱讀畫面）→ `page-settings`
- `e-textbook.css` — App 專屬樣式
- `et-font.css` — 注音字型 `@font-face`，獨立成一個檔案，只在進閱讀畫面時才動態載入
- `js/state.js` — 資料存取：`loadEtLessonList()`／`openEtLesson()`／`_etLoadVocab()`／
  `_etLoadLessonProgress()`／`saveEtProgress()`（`students/{id}/progress/eTextbook`，
  `lessons.<lessonDocId>.foundWords` 持久保存，`lessonDocId` 跟 `lessonTexts`／
  `sharedLessonTexts` 共用同一組 id）／`lookupWord()`（本課生字詞優先用老師解釋，否則查萌典）
- `js/voice.js` — TTS，`etRate`（0.5～1.2 可調）；`etSpeakWithCallback()` 供單句發音完畢後
  取消反白用
- `js/reader.js` — 核心邏輯：`renderEtLessonList()`／`enterEtLesson()`；逐字渲染 + Pointer
  Events 拖曳圈詞；`etHandleCircledText()`／`showEtLookupPopup()`；`etSpeakLine()` 單句發音＋
  反白；`renderFoundWordsPanel()`／`etTapFoundWord()` 已找到生字詞清單（不跨 App 跳轉——
  找到的生字詞真正的練習場景是回題庫測驗，不是識字趣/詞語趣）
- `js/init.js` — 啟動、自動登入（`classIds` 由 Hub 的 `studentMode` 機制保證已載好）、
  載入詞語圖庫、設定頁

## 後台相關檔案

- `admin/quiz-bank.js` — 新增課文全文編輯／分享班級功能（`_qbToggleText()` 等，掛在既有的
  課次列表列上）
- `admin/lesson-fulltext.js`（新檔）— docx/txt/odt/pdf → 純文字轉檔，邏輯搬自
  `apps/quiz/word-to-reader/reader.js`
- `admin/index.html` — 新增 mammoth/JSZip/pdf.js CDN 腳本 + `lesson-fulltext.js`

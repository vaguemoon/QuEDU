# 換算趣 — 百分率與小數、分數換算 設計規劃

> 訪談日期：2026-05-25  
> 狀態：規劃中（訪談暫停，尚有 2 個決策待確認）

## 已確認決策

### 1. 輸入方式

| 答案類型 | 輸入方式 |
|---------|---------|
| 小數（如 0.75） | 虛擬鍵盤新增 `.` 鍵，**只在百分率類別顯示** |
| 分數（如 3/4） | 兩個答案格，**垂直堆疊**（分子上、分母下，仿課本格式） |
| 整數百分率（如 75%） | 現有鍵盤，不需更動 |

### 2. 換算方向（題型）

共 5 個 subtype，對應 `selectSubtype`：

| subtype id | 說明 | 答案格式 |
|-----------|------|---------|
| `pct-to-dec` | 百分率 → 小數 | 1 格，小數（需 `.` 鍵） |
| `dec-to-pct` | 小數 → 百分率 | 1 格，整數 |
| `pct-to-frac` | 百分率 → 分數 | 2 格堆疊（分子/分母） |
| `frac-to-pct` | 分數 → 百分率 | 1 格，整數 |
| `mixed` | 🎲 混合 | **待確認：全混 or 分層混** |

### 3. 分數比對規則

**接受等值分數**：用交叉相乘比對  
`userNum * correctDen === userDen * correctNum`  
（例如 75/100 與 3/4 均視為正確）

### 4. 數值範圍

#### 百分率 ↔ 小數（不分難度）
涵蓋：
- 一位小數：10%=0.1, 20%=0.2, ... 90%=0.9
- 兩位小數：5%=0.05, 15%=0.15, 25%=0.25, 35%=0.35, 45%=0.45, 55%=0.55, 65%=0.65, 75%=0.75, 85%=0.85, 95%=0.95

#### 百分率 ↔ 分數（不分難度）
分母範圍：2, 4, 5, 10, 20, 25, 50  
原則：百分率為整數（無小數點）

常見對照：
- 分母 2：1/2=50%
- 分母 4：1/4=25%, 3/4=75%
- 分母 5：1/5=20%, 2/5=40%, 3/5=60%, 4/5=80%
- 分母 10：1/10=10%, 3/10=30%, 7/10=70%, 9/10=90%
- 分母 20：1/20=5%, 3/20=15%, 7/20=35%, 9/20=45%, 11/20=55%, 13/20=65%, 17/20=85%, 19/20=95%
- 分母 25：1/25=4%, 2/25=8%, 3/25=12%, 4/25=16%, 6/25=24%, 7/25=28%, 8/25=32%, 9/25=36%...
- 分母 50：視情況選入

### 5. 視覺沙盒

**不設計**。此題型不需右側視覺輔助，使用 `game-layout-single`（全寬）。

### 6. 成就/徽章

**不新增**題域徽章。百分率的星數納入整體星數與稱號累計即可。

### 7. 首頁卡片

新增一張卡片：
- 圖示：`📊`（或 `%`，待確認）
- 標題：百分率換算
- 副標題：百分率・小數・分數

### 8. 難度選擇

**不分難度**（`noDifficulty: true`），與長度/重量/容量相同。

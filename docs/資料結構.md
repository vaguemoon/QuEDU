# QuEDU 資料結構（Firestore 資料字典）

> 建立日期：2026-11-13
> 用途：全專案唯一的「有哪些集合、誰讀誰寫、欄位長怎樣」對照表。
> **規則：新增集合、改欄位、改文件 ID 規則之前，先改這份文件，再改程式與 `firestore.rules`。**
>
> 本文件是依程式碼的寫入點整理的「現況」，不是理想設計。標「⚠ 待確認」的項目是只從部分程式碼推得、
> 沒有逐欄核對的地方；標「🔧 待整理」的是已知的不一致，整理計畫見文末。

---

## 一、角色與登入方式

| 角色 | 登入方式 | 身分依據 |
|------|---------|---------|
| super-admin | Google 登入（`super-admin/login.html`） | `superAdmins/{emailKey}` 存在且 `enabled != false` |
| school-admin | 同教師 | `teachers/{uid}.role == 'school-admin'`，範圍限 `schoolId` |
| teacher | Email/密碼 或 Google（`src/auth.js`） | Firebase Auth uid = `teachers/{uid}` |
| student | 學校 → 班級 → 座號 → PIN；或舊制 姓名 + PIN | **不走 Firebase Auth**，PIN 在瀏覽器端比對 |
| 訪客 | 免登入 | `currentStudent.isGuest`，不寫入進度 |

`emailKey` = email 把 `@` 和 `.` 換成 `_`（例：`a_b_gmail_com`）。

學生登入後，Hub 把學生資料存進 `sessionStorage['hub_student']`，各子 app 從這裡取得身分。

## 二、集合總覽

讀寫欄的「公開」＝不需登入；「登入」＝任何 Firebase Auth 使用者（教師）；其餘為更嚴格的條件。

### 帳號與組織

| 集合 | 文件 ID | 讀 | 寫 | 說明 |
|------|--------|----|----|------|
| `superAdmins` | emailKey | 登入可 get；super-admin 可列出 | super-admin | 管理者白名單 |
| `siteSettings` | `main` | 公開 | super-admin | 維護模式、公告 |
| `schools` | 自動 | 公開 | super-admin | 學校 |
| `teachers` | Auth uid | 登入 | 本人（不可改 `role`/`blocked`）；校管理者可封鎖同校教師；super-admin 全權 | 教師帳號 |
| `teachers/{uid}/reader-library` | 檔名 | 本人 | 本人 | 報讀庫（word-to-reader） |
| `classes` | 自動 | 公開 | 建立：登入；改刪：負責教師、該校校管理者、super-admin | 班級 |
| `students` | 自動 或 `姓名_PIN`（舊制）🔧 | 公開 | 公開 🔧 | 學生 |
| `reports` | 自動 | super-admin | 任何人可建立；super-admin 管理 | 使用者回報 |

### 學生的子集合（`students/{id}/…`，目前全部公開讀寫 🔧）

| 路徑 | 說明 |
|------|------|
| `progress/{appKey}` | 各 app 的學習進度，每個 app 一份文件，格式各自不同（見第四節）🔧 |
| `stats/profile` | 練字趣的成就（星星、稱號、登入天數），Hub 也用它顯示稱號 |
| `stats/convertProfile`、`stats/multiplyProfile` | 換算趣、乘法趣的成就 |
| `activities/{自動}` | 活動紀錄（測驗成績等），Hub「最近活動」讀這裡 |
| `strokes/{字}` | 練字趣的筆跡 ⚠ 待確認 |

| 集合 | 文件 ID | 讀 | 寫 | 說明 |

| `questions` | 自動，或由年級＋課次＋字組成的固定 ID（默寫生字） | 公開 | 登入 🔧 | 語文題庫，所有題型共用一個集合，用 `type` 區分 |
| `lessonTexts` | 含教師 uid 的固定 ID | 本人 | 本人 | 教師自己的課文全文 |
| `lessonTexts/{id}/vocab` | 語詞 | 本人 | 本人 | 本課語詞 |
| `lessonTexts/{id}/versions` | 自動 | 本人 | 本人 | 課文版本歷史 |
| `wordImages` | 自動 | 公開 | 登入 🔧 | 詞語圖庫（圖片為 base64） |
| `customCategories` | 自動 | 公開 | 登入 🔧 | 教師自訂詞語類別（`parentId` 形成兩層） |
| `customCategoryAssignments` | 自動 | 公開 | 登入 🔧 | 自訂類別派給哪個班 |
| `charDecompositions` | 字 | 公開 | 登入 | 部件趣：字的拆法 `{ type: 'tb'|'lr', top/bottom 或 left/right }` |
| `radicalGroups` | 部件 | 公開 | 登入 | 部件趣：部件資料 `{ title, variant, phrase, imageUrl, chars }` |
| `zhuyinSounds` | 注音符號 | 公開 | 登入 | 注音趣：37 個符號的圖 ⚠ 欄位待確認 |
| `zhuyinCombinedSounds` | 結合韻 | 公開 | 登入 | 注音趣：22 個結合韻的圖 ⚠ 欄位待確認 |

### 英文、數學、音檔

| 集合 | 文件 ID | 讀 | 寫 | 說明 |
|------|--------|----|----|------|
| `englishImages` | 自動 | 公開 | 登入 🔧 | 英文圖庫（圖片為 base64） |
| `englishUnits` | 單元固定 ID | 公開 | 登入 | 英文單元的發音組合清單 |
| `mathQuestions` | 自動 | 公開 | 登入 🔧 | 數學題組 |
| `audioClips` | 自動 | 公開 | 登入 🔧 | 音檔（base64） |

### 測驗（三科各一套 🔧）

| 科目 | 場次集合 | 成績集合 | 明細 |
|------|---------|---------|------|
| 語文 | `quizSessions` | `quizResults` | `quizResultDetails`（docId 與成績同一筆，只有出題教師可讀） |
| 數學 | `mathQuizSessions` | `mathQuizResults` | 無 |
| 英文 | `englishQuizSessions` | `englishQuizResults` | 寫在成績文件的 `questions` 欄位 |

- 場次：公開讀；登入可建立；只有出題教師（`teacherUid`）能改刪。
- 成績：學生（未登入）可建立，需有 `sessionId`、`score`（0–100 整數）、`studentId`；建立後不可修改。
- 三科成績的讀取與刪除規則不一致 🔧：語文、英文公開讀、出題教師可刪；數學只有登入者可讀、任何人都不能刪。

### 班級的子集合（教師派發給班級的內容，公開讀、登入寫 🔧）

| 路徑 | 文件 ID | 說明 |
|------|--------|------|
| `classes/{id}/sharedQuizSessions` | 場次 ID | 派給這個班的測驗（三科共用） |
| `classes/{id}/sharedLessonTexts` | 課文 ID | 派給這個班的課文快照（課文趣讀這裡） |
| `classes/{id}/sharedReaderDocs` | 檔名 | 派給這個班的報讀文件 |

### 規則裡有、程式碼沒有用到

| 集合 | 說明 |
|------|------|
| `examDrafts` | `firestore.rules` 有規則，但程式碼裡找不到任何讀寫。可能是已移除功能的殘留 ⚠ 待確認後刪除 |

## 三、主要文件的欄位

### `students/{id}`

| 欄位 | 型別 | 說明 |
|------|------|------|
| `name` | string | 姓名 |
| `pin` | string | 4 位數字，**明文** 🔧 |
| `nickname`、`avatar` | string | 學生自己在 app 內設定 |
| `seatNumber` | number | 座號（學校制登入用） |
| `schoolId`、`schoolName` | string | 所屬學校 |
| `classId` | string | 原班（學校制登入用這個欄位查詢）🔧 |
| `classIds` | string[] | 所屬的所有班級（原班＋科任班） |
| `status` | string | `active` / `archived` |
| `type` | string | `trial`＝用邀請碼自行註冊的舊制帳號 |
| `completedTasks` | map | Hub 上勾選完成的班級公告 |
| `createdAt` | number 或 Date 🔧 | 學校制用 `Date.now()`，舊制用 `new Date()` |
| `lastSeen` | — | 最後上線 |

🔧 已知不一致：
- 文件 ID 有兩套：學校制是自動 ID；舊制是 `姓名_PIN`。舊制學生在 Hub 改 PIN 之後文件 ID 不會變，但登入是用 `姓名_新PIN` 去找文件。
- `classId` 與 `classIds` 並存，兩邊都有程式在查。

### `teachers/{uid}`

`uid`、`email`、`displayName`、`schoolId`、`schoolName`、`role`（`teacher` / `school-admin`，沒有此欄位視為 `teacher`）、
`blocked`、`createdAt`、`lastLoginAt`。

### `classes/{id}`

`name`、`grade`、`classNumber`、`classType`（`homeroom` / `subject`）、`schoolId`、`schoolName`、
`teacherUid`（校管理者批次建立、尚未指派教師時為空字串）、`teacherEmail`、`inviteCode`（6 碼）、`active`、
`tasks`（班級公告陣列，每筆 `{ id, text, createdAt }`）、`createdAt`。

### `questions/{id}`

`grade`、`lesson`、`lessonName`、`type`（題型，中文字串，例：`詞語解釋`、`默寫生字`、句子重組等）、
`question`、`answer`、`options`、`teacherUid`、`createdAt`；部分題型另有 `zhuyin`、`hintWord`、`active`。
⚠ 各題型的專屬欄位未逐一核對。

### `wordImages/{id}`

`word`、`definition`、`imageUrl`（base64 data URL）、`grade`、`lesson`、`lessonName`、
`gradeLesson`（`{grade}_{lesson}`，查詢用）、`teacherUid`、`uploadedAt`；自訂類別的圖另有 `customCategoryId`。

### `englishImages/{id}`

`teacherUid`、`grade`、`section`、`unit`、`unitName`、`word`、`phoneticGroup`、`imageUrl`（base64）、`uploadedAt`。

### `lessonTexts/{id}`

`teacherUid`、`grade`、`lesson`、`lessonName`、`fullText`、`pronFixes`（破音字讀音修正）、`updatedAt`。

### 測驗場次

| 集合 | 欄位 |
|------|------|
| `mathQuizSessions` | `teacherUid`、`quizType: 'math'`、`name`、`code`、`totalQuestions`、`operations`、`active`、`createdAt` |
| `englishQuizSessions` | `teacherUid`、`quizType: 'english'`、`name`、`grade`、`sections`、`pool`、`totalQuestions`、`active`、`createdAt` |
| `quizSessions` | `teacherUid`、`name`、`grade`、`lesson`、`lessonName`、`active`、`folder` 等 ⚠ 待確認（含試卷配分、分頁點等設定） |

### 測驗成績

| 集合 | 欄位 |
|------|------|
| `quizResults` | `sessionId`、`sessionCode`、`sessionName`、`teacherUid`、`studentId`、`studentName`、`score`、`correct`、`total`、`grade`、`lesson`、時間欄位 |
| `quizResultDetails` | `sessionId`、`teacherUid`、`studentId`、`studentName`、`score`、`timestamp`、`details`（每題作答） |
| `englishQuizResults` | `sessionId`、`teacherUid`、`studentId`、`studentName`、`score`、`correct`、`total`、`durationSeconds`、`questions[]`、`submittedAt` |
| `mathQuizResults` | `sessionId`、`score`、`studentId` 等 ⚠ 待確認 |

### `students/{id}/activities/{自動}`

共同欄位：`app`（`chinese-quiz` / `math-quiz` / `english-quiz` …）、`score`、`correct`、`total`、`timestamp`（ISO 字串）；
語文另有 `grade`、`lesson`，數學另有 `sessionId`。

## 四、各 app 的進度文件（`students/{id}/progress/{appKey}`）

所有 app 都用 `.set(…, { merge: true })` 寫入，多數帶有 `lastStudied`（ISO 字串）。除此之外沒有共同格式 🔧。

| App | 資料夾 | appKey | 主要欄位 |
|-----|--------|--------|---------|
| 練字趣／識字趣 | `apps/learn/lang/chinese` | `hanzi` | `charStatus` |
| 認字 | `apps/learn/lang/recognize` | `recognize` | `charStatus`、`wordStatus` |
| 部件趣 | `apps/learn/lang/radical` | `radical` | `radicalStatus`、`decompStatus` |
| 注音趣 | `apps/learn/lang/zhuyin` | `zhuyin` | `listenStatus`、`readStatus`、`writeStatus`、`combinedListenStatus`、`combinedReadStatus`、`combinedWriteStatus` |
| 詞語圖卡 | `apps/learn/lang/word-image` | `wordImage` | `words` |
| 課文趣 | `apps/learn/lang/e-textbook` | `eTextbook` | `lessons` |
| 英文趣 | `apps/learn/lang/english` | `english` | 整個 `engProgress` 物件 ⚠ |
| 乘法趣 | `apps/learn/math/multiply` | `multiply` | `masteredFill`、`masteredReverse`、`masteredMixed`、`masteredBest`、`totalCorrect`、`totalAttempts`、`maxStreak`、`examCompletedCount` |
| 換算趣 | `apps/learn/math/convert` | `convert` | ⚠ 待確認 |
| 加減趣 | `apps/learn/math/addsub` | `addsub` | `status` 等 |
| 基礎數感 | `apps/learn/math/numsense` | `numsense` | `totalCorrect`、`totalAnswered`、`totalRounds`、`status` |
| 比較趣 | `apps/learn/math/compare` | `compare` | ⚠ 待確認 |
| 分數趣、幾何趣、移項、知動趣 | `Fractions`、`geometry`、`transpose`、`special/motor` | 無 | 目前不存進度 |

注意 appKey 與資料夾名稱不一定相同（`chinese` → `hanzi`、`word-image` → `wordImage`、`e-textbook` → `eTextbook`）。

## 六、已知問題與整理方向

| # | 問題 | 方向 |
|---|------|------|
| 1 | `students` 與其子集合公開讀寫，PIN 明文 | 無後端前提下：用規則限制可改欄位、禁止未登入刪除、限制列出筆數。要根治需要 Cloud Functions 驗證 PIN |
| 2 | 學生文件 ID 兩套、`classId`/`classIds` 並存 | 全部改自動 ID ＋ `classIds`，寫一次性搬遷腳本 |
| 3 | 進度文件沒有共同格式，Hub 與後台要為每個 app 各寫一段讀取 | `progress/{appKey}` 統一加 `summary`（答對、作答、回合、最後練習時間），app 專屬資料放 `detail` |
| 4 | App 清單散在 Hub 卡片、兩份訊息白名單、後台 `APP_REGISTRY`（只登記 3 個） | 建立 `shared/apps.js` 單一註冊表 |
| 5 | 測驗三套集合、規則不一致 | 場次加 `subject` 欄位合併成一套，舊資料並存一段時間後搬遷 |
| 6 | `questions`、圖庫、音檔、自訂類別、班級子集合：任何登入教師都能改刪別人的資料 | 逐一確認有無跨教師共用的設計後，改成擁有者才能改刪 |
| 7 | 圖片、音檔以 base64 存在 Firestore 文件 | 新上傳改用 Firebase Storage，文件只存網址 |
| 8 | `examDrafts` 規則無對應程式 | 確認後移除 |
